Peak supports language-specific dub tracks, primarily from the ORBIT sub-provider.

## How dubs work

The provider exposes four sub-providers:

- **PRIME** (Apogee) — Main English
- **STELLAR** (Vanguard) — 4K English
- **NEXUS** (Pulse) — Fallback English
- **ORBIT** (Citadel) — Per-language dubs (Hindi, Tamil, Telugu, etc.)

When a source has a quality string like `720p | Hindi`, Peak parses the language
and surfaces it as a dub track.

## Player integration

```js
player.setDub('hi');   // Hindi
player.setDub('ta');   // Tamil
player.setDub('en');   // English
```

### DubsMenu

The DubsMenu appears in the player settings when multiple language renditions are available:

```js
player.on('sourcechange', ({ dub, audioLang }) => {
  console.log('dub:', dub, 'lang:', audioLang);
});
```

## Feature toggle

Dubs are enabled by default. Disable via `/admin/features/dubs`.
