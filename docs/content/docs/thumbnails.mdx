Peak supports thumbnail VTT sprite previews on hover for the seek scrubber.

## How it works

A thumbnail sprite is a single image containing a grid of thumbnails (e.g., 6×6 = 36 frames).
A VTT file maps time offsets to positions in the sprite.

## Sources

Thumbnails come from one of two sources:

1. **Provider-supplied** — Some providers (e.g., PRIME) include a `thumbnailVtt` URL
   in the stream metadata. This is a remote VTT sprite generated by the upstream provider.

2. **Generated on demand** — The API can generate sprites from media segments:

```
POST /api/v1/thumbnails/{type}/{id}
{ "type": "movie", "id": "550" }
```

Response:

```json
{
  "success": true,
  "thumbnailVtt": "/api/v1/thumbnails/movie_550_thumbs.vtt",
  "thumbnailSprite": "/api/v1/thumbnails/movie_550_sprite.jpg"
}
```

## Player integration

The player loads the VTT automatically when available:

```js
player.on('meta', (meta) => {
  console.log('thumbnails available:', !!meta.thumbnailVtt);
});
```

Thumbnail loading is controlled by the `scrubber-thumbnails` feature toggle in the admin UI.

## Files

- `utils/thumbnailService.js` — sprite generation + caching
- `player/src/components/player/media/useThumbnailVtt.ts` — VTT loading
- `player/src/components/player/media/useScrubberThumbnails.ts` — scrubber integration
- `routes/thumbnailRoutes.js` — thumbnail API routes
