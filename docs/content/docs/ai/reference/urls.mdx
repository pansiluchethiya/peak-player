## Player routes

| Pattern | Description |
|---|---|
| `/` | Landing page |
| `/movie/{tmdbId}` | Movie player |
| `/tv/{tmdbId}/{season}/{episode}` | TV player |
| `/live/{channelId}` | Live TV player |
| `/embed/movie/{tmdbId}?token=...` | Embedded movie |
| `/embed/tv/{tmdbId}/{season}/{episode}?token=...` | Embedded TV |
| `/embed/live/{channelId}?token=...` | Embedded live |
| `/embed/demo` | Demo session |

## Provider query parameters

```
GET /api/streams/{provider}/{type}/{tmdbId}
  ?source={provider}      // specific provider
  ?season={n}             // TV season
  ?episode={n}            // TV episode
  ?invalidate=1           // bypass cache
```

Providers: `netmirror`, `vixsrc`, `vidlink`, `videasy`, `zxcstreams`,
`vaplayer`, `showbox`, `4khdhub`, `castletv`, `dahmermovies`,
`hdghartv`, `onetouchtv`, `streamflix`, `rive apogee`,
`rive vanguard`, `rive pulse`, `rive citadel`.

Technical keys are used in query params. Display codenames (PRIME, STELLAR, etc.)
are resolved client-side from `player/src/lib/servers.ts`.
