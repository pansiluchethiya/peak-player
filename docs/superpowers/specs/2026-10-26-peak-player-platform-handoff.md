## 5. Bugs found, by status

### 5.1 Open — and the reason the player is being rebuilt

**Video.js VHS cannot decode the proxied HLS.** Diagnostic at
`/embed/movie/550?token=…` after the host-div refactor:

```json
{"videoCount": 1,
 "videos": [{"cls": "vjs-tech", "readyState": 0, "paused": false,
             "duration": 8348, "w": 0, "h": 0, "src": "blob:…", "connected": true}],
 "accent": "#e5e5e5", "errorCard": true,
 "errorText": "Stream unavailable / This stream is unavailable in the embedded player."}
```

The manifest parses (duration is correct) but no frames decode. Our hls.js path
played the identical stream to `readyState 4` with advancing `currentTime`. Two
engines, two behaviours — which is exactly what the spec's D1 removes.

### 5.2 Open — folded into the spec's bug table (§13)

1. `/movie/999999` never leaves "Preparing stream…" — no error transition.
2. Player home `/` hero heading **"Your frame."** is near-white on white in light mode (invisible).
3. `/tv/1399/1/1` and `/embed/tv/…` log `404` on `GET /api/v1/stream/events/tv/1399/1/1?fpHash=…&ua=…` — the API has no SSE route for that shape.
4. `.error-card p` uses `color-mix(in srgb, var(--color-fg) 7%, transparent)` → the error message is almost unreadable.
5. Legacy static admin at `http://localhost:8787/` still renders "at its peak." in `#333333` on a permanently black panel (same class of bug already fixed in the Next.js admin).
6. Next.js dev "N" badge overlaps the sidebar / player corner — consider `devIndicators: false`.
7. `/login` intermittently logs a hydration-mismatch warning, only on a cold first compile. Never reproduced on a warm server.
8. `/movie/550` document title is `Peak — Peak` (the metadata effect appends `— Peak` on top of page metadata that already does). Disappears once real titles land.
9. **Zero IPTV channels/playlists configured** — `/api/v1/live/tv/channels` returns `{"channels":[],"nextCursor":null}` and `/api/admin/iptv/groups` returns `{"groups":[]}`. Live routes can only be tested for graceful degradation today.

### 5.3 Fixed (uncommitted, verified at least once)

- Embed iframe returned 500 / `frame-ancestors 'none'` because `EMBED_TOKEN_SECRET` was missing from the player runtime.
- HLS variant playlists and AES keys were not proxied.
- Spurious `STREAM_UNAVAILABLE` sent to the parent while playback was succeeding (now gated on `fatalError`).
- Video.js 10 `VJS8_LEGACY_INIT` failure (pinned to 8.x).
- Green `#2f6b4f` accent bleeding through `--accent`.
- Admin rendered largely unstyled — 72 of 105 class names had no CSS.
- Invisible "at its peak." on the admin auth story panel in light mode.
- Dead health chip, dead restart/sign-out/nav-toggle buttons.
- Dashboard was a stub with no auth check and no data.

falls back to the literal string `'Peak'` for every title — which is why the
player header says "Peak" and the tab title is "Peak — Peak". The spec replaces
this with a keyless Wikidata + Wikipedia + TVMaze chain (§7 of the spec).

## 7. The design that supersedes the remaining work

Spec: `docs/superpowers/specs/2026-10-26-peak-player-platform-design.md`
(committed as `a0abafe`, 612 lines, 19 sections).

In one line each:

- **D1** — one engine: `@videojs/react@10.2.0` with its `hls` adapter. Delete
  `video.js@8`, the hand-written hls.js path, and `VideoJsPlayer.tsx`.
- **D2** — vendored Shadcn skin source, so the UI is editable and there is only
  ever one UI.
- **D3–D6** — Mux Data (silently inert without a key), thumbnails (image
  stream, ffmpeg sprite fallback), custom mica captions, a control superset
  (episode nav, quality, audio, speed, captions, live/DVR, stats, chapters,
  cast, share, aspect, keyboard help, colour correction, codenamed server
  switcher, 300 %/500 % volume boost).
- **D7–D11** — metadata + artwork service with a fallback chain that cannot
  fail; IPTV catalogue seeded from iptv-org, validated, synced every 3 h, with
  full EPG; three preference modes (browser / server / user); muted autoplay;
  i18n-ready English.
- **D12** — SDK v2 with full parity and exhaustive docs.

Phases: **P1** engine + skin, **P2** metadata + artwork, **P3** IPTV + EPG,
**P4** controls + preferences + SDK + docs. Each ends with `npm run check`
green and a visual sweep.
